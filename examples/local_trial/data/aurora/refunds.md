# Aurora refunds / 退款规则 [SYNTHETIC]
This entire document describes a fictional store. 全文为合成测试资料，不是真实商家的承诺。
## Return window / 退货期限
Aurora accepts unused accessories within 21 calendar days of delivery. Aurora 的未使用配件可在签收后 21 个自然日内退货。The original package and a synthetic order number are required. The return clock starts on delivery, not on purchase.
## Exceptions / 例外
Aurora does not refund downloaded digital patterns. 已下载的数字图样不能退款。Shipping charges are not included in the accessory refund; a missing parcel follows the shipping policy instead.
