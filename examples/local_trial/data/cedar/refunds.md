# Cedar refunds / 退款规则 [SYNTHETIC]
This entire document describes a fictional store. 全文为合成测试资料，不是真实商家的承诺。
## Return window / 退货期限
Cedar accepts unused accessories within 35 calendar days of delivery. Cedar 的未使用配件可在签收后 35 个自然日内退货。The original package and a synthetic order number are required. The return clock starts on delivery, not on purchase.
## Exceptions / 例外
Cedar refunds downloaded digital patterns only if the file is corrupted. Cedar 仅在文件损坏时退款已下载的数字图样。Shipping charges are not included in the accessory refund; a missing parcel follows the shipping policy instead.
